# Code Statistics

Source-line snapshot of the oracle monorepo. **Update this whenever the
numbers drift materially** by running the counter and pasting fresh output.

```bash
./scripts/stats.sh   # run from repo root, in a git work tree
```

## How the count works

- **Git-tracked files only.** `stats.sh` starts from `git ls-files`, so
  ignored artifacts (`.env`, `node_modules`, build output, SQLite db files,
  bun/go caches) never count, and only committed code is measured.
- **Plain line counts** (`wc -l`). Includes blank lines and comment lines.
  It is NOT "logical" or "code-only". Blank/comment lines inflate every
  bucket by a similar factor, so ratios (below) stay meaningful.
- The script sums per-file rows and skips `wc`'s aggregate `total` row, so
  nothing is double-counted and single-file buckets tally correctly.
- It relies on `grep -z`/`xargs -0` because several web file paths contain
  characters (`+`, `@`, `(`/`)`) that break naive `xargs` word-splitting.

## Definitions

| Metric         | `stats.sh` var   | What it includes                                                                    |
| -------------- | ---------------- | ----------------------------------------------------------------------------------- |
| Go total       | `go_total`       | Every `apps/api/**/*.go`, including tests and sqlc output                           |
| Go source      | `go_source`      | `*_test.go` and `internal/store/db/` removed                                        |
| Go tests       | `go_test`        | All `*_test.go`                                                                     |
| Go generated   | `go_generated`   | sqlc output in `internal/store/db/` (regenerated by `make sqlc`, never hand-edited) |
| Web total      | `web_total`      | Svelte + TS/JS + CSS under `apps/web/**`                                            |
| Web svelte     | `web_svelte`     | `.svelte` components                                                                |
| Web ts/js      | `web_tsjs`       | `.ts` and `.js` (api lib, `+layout`/`+page` TS, `server.js`)                        |
| Web css        | `web_css`        | `.css`                                                                              |
| SQL migrations | `sql_migrations` | goose migration `.sql` files                                                        |
| SQL queries    | `sql_queries`    | sqlc query `.sql` input                                                             |
| Other          | `other`          | Lockfiles, configs, docs, static assets (non-Go, non-web-source)                    |
| Repo total     | `repo_total`     | **Every** tracked file in the repo                                                  |
